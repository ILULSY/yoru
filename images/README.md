# Images locales

Déposez ici vos propres visuels (ex. `mon-article.jpg`), puis référencez-les dans un article :

```ts
cover: "/images/mon-article.jpg",
```

ou ajoutez-les à la médiathèque `data/media.ts` (recommandé : texte alternatif, dimensions et crédit).
Les images locales sont optimisées automatiquement par `next/image` (AVIF/WebP, tailles adaptées).
